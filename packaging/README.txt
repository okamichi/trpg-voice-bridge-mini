TRPG Voice Bridge Mini

FVTT・ユドナリウム・ココフォリアなどのVTTの公開チャットVTT（オンラインセッションツール）のチャットにキャラとして書いたセリフを、そのキャラの声でDiscordのボイスチャンネルで読み上げるツールです。

TRPG Voice Bridgeの機能を絞った、Discord専用版です。音声生成エンジン（nyosegawa/speech.cpp）と音声モデル（Irodori-TTS-v4.1-Small）を同梱しているので、モデルのダウンロードは要りません。操作と声づくりは、すべてDiscord上で行います。

■ 0. 用意するもの

PC : macOS（Apple Silicon）か、Windows（x64）
ブラウザ : Google Chrome (VTTのチャットを取り込む拡張機能 Collector を入れます)
Discordのサーバー : Botを招待するので、サーバーの管理者権限が必要（なければ招待を管理者に代行してもらう）
Discord Bot : 自分で作ります（手順1）

GPU : MacはMetal, WindowsはVulkan(なければCPU動作)、メモリを2GB消費

このツールを動かすのは、卓の中の1人（ここでは「音声担当者」と呼びます）だけです。GMでもPLでも構いません。ほかの参加者は、いつもどおりVTTとDiscordを使うだけで、何も入れる必要はありません。

■ 1. Discord Botを作る（初回だけ）

1. Discord Developer Portal（https://discord.com/developers/applications）で「New Application」を押し、名前を付けてアプリケーションを作ります。
   ・作成したら「General Information」の「Application ID」を控えておきます。
2. 左のメニューの「Bot」で「Reset Token」を押し、表示されたトークンをコピーします。
   ・トークンは一度しか表示されません。なくしたら、もう一度「Reset Token」で作り直してください。
   ・「Privileged Gateway Intents」はすべてオフのままにします。
3. Botをあなたのサーバーに呼びます。サーバー管理者権限が必要なので権限がない場合は招待URLを管理者に開いてもらって下さい。
   ・控えておいた「Application ID」を、次のURLの <Application ID> の部分に入れて開きます。
   ・https://discord.com/oauth2/authorize?client_id=<Application ID>&scope=bot&permissions=3247104
   ・このURLは、2.で起動したときにも画面に表示されます。

※ Botに「管理者（Administrator）」権限は付けないでください。必要な権限（ボイスチャンネルへの接続と発言、テキストチャンネルの閲覧・メッセージ送信・ファイル添付・履歴閲覧）は、招待URLに含まれています。

■ 2. 起動する

展開したフォルダの中で起動します。実行ファイルだけを別の場所へ移すと動きません。

macOS: ターミナルで ./trpg-voice-bridge-mini
Windows: trpg-voice-bridge-mini.exe

1. 音声モデルの読み込みが始まります。
2. 初回は、Discord Botのトークンを聞かれます。貼り付けてEnterを押します。
   ・トークンは data/discord.json に保存され、次回からは聞かれません。
3. Botがまだどのサーバーにも入っていない場合は、招待URLが表示されます。ブラウザで開き、サーバーを選んで「認証」を押します。
4. 「準備ができました」と表示されたら、Discordで操作できます。

終了するには、起動した画面でCtrl+Cを押します。同梱の音声生成も一緒に停止します。

■ 3. 卓で使う

1. 自分がボイスチャンネルに入った状態で、Discordのテキストチャンネル(声の設定専用チャンネルを別途作るのが望ましい)に /bridge join と入力します。
   ・Botは、入力した人がいるボイスチャンネルに入り、読み上げを始めます。
   ・通知と声づくりのフォームは、このコマンドを実行したテキストチャンネルに出ます。スレッドやボイスチャンネルのチャットではなく、Botがメッセージの送信とファイルの添付をできる、通常のテキストチャンネルで実行してください。
   ・チャンネルを変えたいときは、別のチャンネルでもう一度 /bridge join と入力します。起動し直したときも、もう一度入力します。
2. ChromeでVTTを開き、拡張設定からCollectorのアイコンを押して「このタブを接続」を押します。
   ・初回は、Collectorに確認コードが表示され、Discordにも同じコードの通知が出ます。コードが同じなら、通知の「承認」を押します。承認できるのは /bridge join を実行した人だけです。
   ・承認したら、VTTのタブでもう一度「このタブを接続」を押します。
3. キャラがVTTのチャットで発言すると、そのキャラの声で読み上げます。声がまだないキャラの発言は読み上げません。
4. 終わるときは /bridge leave と入力します。読み上げを止め、Botがボイスチャンネルから退出します。

■ 4. キャラの声を作る

声は、キャラの名前に付きます。VTTや部屋が変わっても、同じ名前のキャラは同じ声で読み上げます。別の声にしたいキャラは、別の名前にしてください。全角と半角の違い、前後の空白は、同じ名前として扱います。

声は、VTTのチャットでそのキャラとして発言して作ります。

・説明文を付けて、すぐに登録する

    （ブリッジ声登録）若くて透き通るような女性の声。

  説明文から声を作り、そのキャラに割り当てます。読み上げ中なら、確認のセリフがボイスチャンネルに流れます。

・説明文を付けずに、Discordで試聴しながら作る

    （ブリッジ声登録）

  /bridge join を実行したテキストチャンネルに、「声を作る」ボタンが出ます。この時点では、まだ音声は作りません。
  ボタンを押して声の説明を入力し、送信すると、声づくりのフォームと試聴用の音声が出ます。音声を再生して確かめ、「この声に決定」を押します。
  「基本設定」で声の説明を、「詳細設定」でseedを変えて、「変更を反映して再生成」で何度でも作り直せます。
  すでに声があるキャラでは、今の声の説明が入力欄に入った状態で始まります。
  「詳細設定」ではCFGも変えられます。空欄ならモデルの既定値（カッコ内）を使います。
    テキストCFG（3）：読み上げる文への従い方を調整します
    説明CFG（3）：声の説明や演技の指示への従い方を調整します
    参照音声CFG（5）：元になった音声の声質への従い方を調整します
  CFGは高いほどよいわけではなく、上げすぎると音声が不自然になることがあります。1つずつ少しずつ変えて、試聴しながら決めてください。
  声づくりの画面は、開いてから10分たつと使えなくなります。同じテキストチャンネルにいる人なら、誰でも操作できます。

・声を外す

    （ブリッジ声削除）

Discordから始めることもできます。/bridge voice と入力し、character にキャラ名、description に声の説明を入れると、同じフォームが出ます。
  ・まだ発言していないキャラの声も、名前を入力して先に作れます。
  ・description を省略すると、今の声をもとに作り直します。

声を作り直したり外したりすると、そのキャラが使っていた以前の声は、ほかのキャラが使っていなければ削除されます。
声を付けなかった名前は、次に起動したときに片付けます。
声は500件まで登録できます。上限に達したら、使わなくなったキャラとして （ブリッジ声削除） と発言し、声を外してください。

■ 5. 演技の指示

チャットのテキストに絵文字か全角の丸カッコで指示を書くと、感情や演技を付けられます。丸カッコの指示は読み上げから取り除きます。

  （怒り）ふざけるな！（間）……もういい。
  😲えっ、本当に？
  （演技:震える声で、怯えながら）誰か……いるの？

使える単語と絵文字：
  喜び😆 怒り😠 悲しみ😭 驚き😲 心配😟 緊張😰 安堵😌 自信😎 照れ🫣 囁き・ささやき・小声👂 優しく🫶 笑い🤭 ため息😮‍💨 早口⏩ ゆっくり🐢 叫び😱 眠そう😪 懇願🙏 ナレーション📖 間⏸️

（演技:説明）または（感情:説明）と書くと、その発言全体の演技指示になります。指示は1つ100文字まで、合計200文字までです。上の単語でも「演技:」「感情:」付きでもない丸カッコは、本文として読み上げます。

■ 6. Collectorを入れる

Collectorは、VTTのチャットを取り込むChrome拡張です。音声担当者一人だけが入れます。

1. Chromeで chrome://extensions を開き、デベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」で、同梱の collector/ を選びます。
3. VTTのタブでCollectorのアイコンを押し、「このタブを接続」を押します。

接続したあとの新しい公開キャラ発言だけを読み上げます。表示済みの履歴、ささやきやシークレットの発言、ダイスだけの発言は読み上げません。

■ データの保存先

設定と声は、展開したフォルダの data/ にまとめて保存します。

  data/bridge.sqlite            キャラ、声の設定、キャラと声の割り当て
  data/voices/                  声の元になる音声
  data/reference-voices.json    その管理情報
  data/discord.json             Discord Botのトークン

・バックアップは、終了してから data/ フォルダを丸ごとコピーします。
・新しい版に更新するときは、新しいZIPを展開したあと、古いフォルダの data/ を新しいフォルダへ移します。移さないと、キャラと声が空の状態で始まり、トークンも入力し直しになります。
・data/ はTRPG Voice Bridgeの保存先と同じ形式です。

■ 起動オプション

  --help / --version
  --data-dir <path>     保存先（既定は展開したフォルダの data/）
  --port <1-65535>      Collectorを受け付けるポート（既定8090）
  --tts-port <1-65535>  同梱の音声生成のポート（既定18088）
  --steps <1-100>       音声生成のステップ数（既定12）。増やすと生成に時間がかかります
  --tts-backend <vulkan|cpu>  Windowsで音声生成の種類を指定
  --self-test           SQLite・Discordの部品・音声変換の診断（通信しません）

トークンは、環境変数 TRPG_VOICE_BRIDGE_DISCORD_TOKEN でも指定できます。

Windowsでは、GPU（Vulkan）を使う版で音声生成を始め、使えない場合はCPUの版に切り替えます。

TRPG Voice Bridgeと同時に起動する場合は、--port と --tts-port で別のポートを指定し、Discord Botも別のものを使ってください。

■ 起動時の警告について

macOS版はAppleによる公証を受けていません。Windows版はコード署名がありません。
初回起動時にOSの確認や警告が表示される場合があります。

macOSで開発元を確認できない旨の警告が出た場合:
  入手元と同梱のSHA-256を確認し、起動を試した後で、
  「システム設定」→「プライバシーとセキュリティ」の「このまま開く」を確認してください。
  trpg-voice-bridge-miniだけでなく、runtime/speech内のspeechやbridge-supervisor、ネイティブ依存にも
  確認が必要な場合があります。
  Appleの案内: https://support.apple.com/ja-jp/102445

■ 利用上の注意

・実在の人物（声優・著名人など）の声や、版権作品のキャラクターの声を、本人や権利者の許可なく、まねて作ったり使ったりしないでください。
・そのような声で作った音声や、それを含む録画・配信などを公開しないでください。
・人をだます目的の音声（なりすましやフェイク）を作らないでください。
・声の説明から作った声が、偶然に実在の人物の声に似る場合があります。
・同梱している音声モデルのライセンスと利用上の制限（モデルカードの記載）に従ってください。ライセンス文と制限の内容は licenses/model/ にあります。

■ チャットデータについて

・本ツールは、ブラウザ拡張（Collector）を使用して、対応するVTTの画面上に表示されたチャットデータを取得し、音声読み上げに利用します。
・Collectorは上記の目的のみで動作し、VTTへのチャット送信やゲームデータの変更は行いません。作った音声は、Discordのボイスチャンネルで卓の参加者に流れます。
