# TRPG Voice Bridge Mini

VTT（オンラインセッションツール）のチャットにキャラとして書いたセリフを、そのキャラの声でDiscordのボイスチャンネルで読み上げるツールです。

[TRPG Voice Bridge](https://github.com/okamichi/trpg-voice-bridge) の機能を、Discordで使う分だけに絞った簡易版です。音声を作るプログラムnyosegawa/speech.cppと音声モデルIrodori-TTS-v4.1-SmallのGGUF版が入っているので、ダウンロードして起動し、Discord Botのトークンを入力すれば使えます。設定画面はなく、操作はすべてDiscordで行います。

## できること

- ココフォリア・FVTT・ユドナリウムのチャットの発言を、キャラごとの声で読み上げる
- 声は「どんな声か」を文章で書くだけで作れる
- `（怒り）` や `😲` のように書くと、感情や演技を付けられる
- 音声は自分のパソコンの中で作るので、外部の音声サービスを使わない

## 必要なもの

| もの              | 説明                                                   |
| ----------------- | ------------------------------------------------------ |
| パソコン          | macOS（Apple Silicon）か、Windows（x64）               |
| Google Chrome     | VTTのチャットを取り込む拡張機能（Collector）を入れます |
| Discordのサーバー | Botを招待するので、サーバーを管理できる権限が必要です  |
| Discord Bot       | 自分で作ります（手順1）                                |

※ GPU(MacはMetal, WindowsはVulkanを使用)のメモリを2GB使用します。WindowsはGPUがVulkanに対応していない場合はCPUで動作します。

このツールを動かすのは、卓の中の1人（ここでは「音声担当者」と呼びます）だけです。GMでもPLでも構いません。ほかの参加者は、いつもどおりVTTとDiscordを使うだけで、何も入れる必要はありません。

## 使い方

### 1. Discord Botを作る（最初の1回だけ、あらかじめ準備しておく）

1. [Discord Developer Portal](https://discord.com/developers/applications) を開き、「New Application」を押します。名前を付けて作成します。
   - 作成したら「General Information」の「Application ID」を控えておきます。
2. 左のメニューの「Bot」を開き、「Reset Token」を押します。表示された文字列（トークン）をコピーして、手元に控えます。
   - トークンは一度しか表示されません。なくしたら、もう一度「Reset Token」を押して作り直します。
   - トークンはパスワードと同じです。人に見せないでください。
   - 同じ「Bot」の画面にある「Privileged Gateway Intents」は、すべてオフのままにします。
3. Botをあなたのサーバーに呼びます。サーバー管理者権限が必要なので権限がない場合は招待URLを管理者に開いてもらって下さい。
   - 控えておいた「Application ID」を、次のURLの <Application ID> の部分に入れて開きます。
   - https://discord.com/oauth2/authorize?client_id=<Application ID>&scope=bot&permissions=3247104
   - このURLは、2.で起動したときにも画面に表示されます。

### 2. ダウンロードして起動する

1. [リリース情報](https://github.com/okamichi/trpg-voice-bridge-mini/releases)のページから、自分のパソコン用のZIPをダウンロードして展開します。
   - macOS：`trpg-voice-bridge-mini-（バージョン）-darwin-arm64.zip`
   - Windows：`trpg-voice-bridge-mini-（バージョン）-win32-x64.zip`
2. 展開したフォルダの中にある実行ファイルを起動します。フォルダの中身は、まとめて置いたままにしてください。実行ファイルだけを別の場所に移すと動きません。
   - macOS：`trpg-voice-bridge-mini`（ターミナルで `./trpg-voice-bridge-mini`）
   - Windows：`trpg-voice-bridge-mini.exe`
3. 画面の表示に従って進めます。
   1. 「音声モデルを読み込んでいます」と表示されます。
   2. 初めての起動では、トークンを聞かれます。手順1でコピーしたトークンを貼り付けて、Enterを押します。次回からは聞かれません。
   3. 招待URLが表示されたら、ブラウザで開きます。Botを入れるサーバーを選んで「認証」を押します。
   4. 「準備ができました」と表示されたら、準備完了です。

遊んでいる間は、この画面を閉じないでください。終わるときは、この画面でCtrl+Cを押します。

初めて起動するとき、OSの警告が出ることがあります。対処は「[起動時の警告](#起動時の警告)」を見てください。

### 3. Collectorを入れる（最初の1回だけ）

Collectorは、VTTのチャットを取り込むChromeの拡張機能です。音声担当者だけが入れます。

1. Chromeのアドレス欄に `chrome://extensions` と入力して開きます。
2. 右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダの中の `collector` フォルダを選びます。

対応しているVTTは、ココフォリア、FVTT（12・13・14）、ユドナリウム with Fly、ユドナリウムです。

### 4. 卓で遊ぶ

1. Discordで、**自分が対象のボイスチャンネルに入ります。**
2. **テキストチャンネル（声の設定用に作るのが望ましい）に `/bridge join` と入力**します。Botが同じボイスチャンネルに入り、読み上げが始まります。
   - Botは、入力した人がいるボイスチャンネルに入ります。
   - 通知や声づくりの画面は、入力したテキストチャンネルに出ます。スレッドやボイスチャンネルのチャットではなく、通常のテキストチャンネルで入力してください。
   - チャンネルを変えたいときは、別のチャンネルでもう一度 `/bridge join` と入力します。起動し直したときも、もう一度入力します。
3. ChromeでVTTを開き、拡張設定のCollectorのアイコンを押して「このタブを接続」を押します。
   - 初めて接続するときは、Discordに確認コードと「承認」ボタンが出ます。Collectorに表示されたコードと同じなら「承認」を押し、もう一度「このタブを接続」を押します。
4. キャラの声を作ります（次の節）。声のあるキャラがVTTのチャットで発言すると、その声で読み上げます。
5. 終わったら `/bridge leave` と入力します。Botがボイスチャンネルから出ます。

## キャラの声を作る

声は、VTTのチャットに、そのキャラとして書いて作ります。

**すぐに声を付ける**

```text
（ブリッジ声登録）落ち着いた、やさしい女性の声。
```

`（ブリッジ声登録）` のあとに、どんな声かを書きます。その説明から声を作って、そのキャラに付けます。

**試聴しながら作る**

```text
（ブリッジ声登録）
```

説明を書かずに送ると、Discordに「声を作る」ボタンが出ます。ボタンを押して声の説明を書くと、試聴できる音声が出ます。気に入ったら「この声に決定」を押します。説明を変えて、何度でも作り直せます。

**声を外す**

```text
（ブリッジ声削除）
```

覚えておくこと：

- 声はキャラの名前ごとに付きます。
- 同じ名前なら、部屋やVTTが変わっても同じ声で読み上げます。別の声にしたいときは、別の名前にします。
- 声を付けていないキャラの発言は、読み上げません。声のいらないNPCは、そのままで大丈夫です。
- Discordで `/bridge voice` と入力しても作れます。まだ発言していないキャラの声も、名前を入れて先に作れます。

### Discordの声づくりの画面

「声を作る」ボタンや `/bridge voice` から始めると、テキストチャンネルに声づくりの画面が出ます。ボタンで設定を変えて試聴し、気に入ったら「この声に決定」を押します。

| ボタン               | すること                                                         |
| -------------------- | ---------------------------------------------------------------- |
| 基本設定             | 声の名前、声の説明、話す速度（0.5〜2）、試聴するセリフを変えます |
| 詳細設定             | seedとCFGを変えます（下の表）                                    |
| 既存の声             | 登録済みの声を選んで、その設定を使います                         |
| 参照音声             | 登録済みの声の元になった音声を選んで使います                     |
| 変更を反映して再生成 | 今の設定で、試聴用の音声を作り直します                           |
| この声に決定         | 試聴した音声で声を登録し、キャラに付けます                       |
| 取消                 | 声づくりをやめます                                               |

詳細設定で変えられるもの：

| 項目        | 内容                                         | 空欄のとき |
| ----------- | -------------------------------------------- | ---------- |
| seed        | 数字を変えると、同じ説明でも別の声になります | —          |
| テキストCFG | 読み上げる文への従い方を調整します           | 3          |
| 説明CFG     | 声の説明や演技の指示への従い方を調整します   | 3          |
| 参照音声CFG | 元になった音声の声質への従い方を調整します   | 5          |

CFGは、高いほどよいわけではありません。上げすぎると、音声が不自然になることがあります。1つずつ少しずつ変えて、試聴しながら決めてください。

- この画面は、開いてから10分たつと使えなくなります。そのときは、もう一度始めます。
- 同じテキストチャンネルにいる人なら、誰でも操作できます。声づくりが苦手な人の分を、ほかの人が作ることもできます。

## 感情や演技を付ける

セリフの中に、絵文字か、全角の丸カッコで指示を書きます。丸カッコの指示は読み上げません。

```text
（怒り）ふざけるな！（間）……もういい。
😲えっ、本当に？
（演技:震える声で、怯えながら）誰か……いるの？
```

使える言葉と絵文字：

喜び😆 怒り😠 悲しみ😭 驚き😲 心配😟 緊張😰 安堵😌 自信😎 照れ🫣 囁き・ささやき・小声👂 優しく🫶 笑い🤭 ため息😮‍💨 早口⏩ ゆっくり🐢 叫び😱 眠そう😪 懇願🙏 ナレーション📖 間⏸️

`（演技:〜）` や `（感情:〜）` と書くと、自由な文章で指示できます。上の言葉でも「演技:」「感情:」付きでもない丸カッコ（例：`（小さく笑う）`）は、そのまま読み上げます。

## うまくいかないとき

| 表示・様子                                           | すること                                                                                      |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 「先にボイスチャンネルに入ってから実行してください」 | 自分がボイスチャンネルに入ってから `/bridge join` を入力します                                |
| 「内蔵TTSの準備中です」                              | 起動した画面に「準備ができました」と出るまで待ちます                                          |
| 「通常のテキストチャンネルで実行してください」       | スレッドなどではなく、Botがメッセージを送れる通常のテキストチャンネルで入力します             |
| 「承認できるのは /bridge join を実行した人だけです」 | `/bridge join` を入力した人が「承認」を押します                                               |
| キャラの発言が読み上げられない                       | そのキャラに声を付けているか確かめます。`/bridge join` の返事に、声のないキャラの名前が出ます |
| 2回目からトークンを聞かれる                          | `data` フォルダが消えていないか確かめます（次の節）                                           |

## データの保存とバックアップ

キャラ・声・トークンは、展開したフォルダの中の `data` フォルダにまとめて保存します。

- バックアップは、ツールを終了してから `data` フォルダを丸ごとコピーします。
- 新しいバージョンに入れ替えるときは、新しいZIPを展開したあと、古いフォルダの `data` を新しいフォルダに移します。移さないと、声が空の状態で始まり、トークンも入れ直しになります。
- `data` の中にはトークンが入っています。人に渡さないでください。

## 起動オプション

起動するときに、次のように指定できます（例：`./trpg-voice-bridge-mini --steps 20`）。

| オプション                    | 内容                                                                                                                         |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `--data-dir <場所>`           | データの保存先を変えます。卓ごとに分けたいときに使います                                                                     |
| `--steps <1〜100>`            | 音声を作るときのステップ数です（最初は12）。増やすと精度はあがりますが、作るのに時間がかかります                             |
| `--port <番号>`               | Collectorの接続を受け付けるポートです（最初は8090）                                                                          |
| `--tts-port <番号>`           | 音声を作るプログラムのポートです（最初は18088）                                                                              |
| `--tts-backend <vulkan\|cpu>` | Windowsで、音声をGPU（vulkan）とCPU（cpu）のどちらで作るかを選びます。指定しないとGPUで始め、使えないときはCPUに切り替えます |

トークンは、環境変数 `TRPG_VOICE_BRIDGE_DISCORD_TOKEN` でも指定できます。

TRPG Voice Bridgeと同時に起動するときは、`--port` と `--tts-port` で別の番号を指定し、Discord Botも別のものを使ってください。

## 起動時の警告

macOS版はAppleの公証を受けておらず、Windows版にはコード署名がありません。そのため、初めて起動するときに警告が出ることがあります。

- **macOS**：「開発元を確認できない」という警告が出たら、「システム設定」→「プライバシーとセキュリティ」を開き、このアプリの「このまま開く」を押します。フォルダの中の `runtime/speech` にある `speech` や `bridge-supervisor` についても、同じ確認が出ることがあります。（[Appleの案内](https://support.apple.com/ja-jp/102445)）
- **Windows**：警告の「詳細情報」を押し、「実行」を押します。

## ソースから起動する

macOS（Apple Silicon）かWindows（x64）で、Node.js 22.x以上と、CMakeとC++のビルド環境が必要です。

```bash
git clone https://github.com/okamichi/trpg-voice-bridge-mini
cd trpg-voice-bridge-mini
npm ci
npm --prefix discord ci
npm run package:speech
npm run package:model
npm start
```

`npm run package:speech` は音声を作るプログラム（speech.cpp）をビルドします。`npm run package:model` は音声モデル（約0.86GB）をダウンロードします。データはリポジトリの中の `data` フォルダに保存します。

## 利用上の注意

- 実在の人物（声優・著名人など）の声や、版権作品のキャラクターの声を、本人や権利者の許可なく、まねて作ったり使ったりしないでください。
- そのような声で作った音声や、それを含む録画・配信などを公開しないでください。
- 人をだます目的の音声（なりすましやフェイク）を作らないでください。
- 声の説明から作った声が、たまたま実在の人物の声に似ることがあります。
- 同梱している音声モデルのライセンスと利用上の制限（モデルカードの記載）に従ってください。
- 本ソフトウェアの利用によって生じたいかなる損害についても、作者は責任を負いません（[LICENSE](LICENSE)も参照）。

## チャットデータについて

- 本ツールは、ブラウザ拡張（Collector）を使用して、対応するVTTの画面上に表示されたチャットデータを取得し、音声読み上げに利用します。
- Collectorは上記の目的のみで動作し、VTTへのチャット送信やゲームデータの変更は行いません。作った音声は、Discordのボイスチャンネルで卓の参加者に流れます。
